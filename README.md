# سامانه جامع خودشناسی و تحول زندگی | «خودآگاه» (KhodAgah)

> **یک وب‌اپلیکیشن پیشرو (PWA)، آفلاین و مبتنی بر روان‌شناسی تحلیلی کارل گوستاو یونگ و علوم شناختی-رفتاری (CBT / ACT)**

---

## ۱. فلسفه و هویت محصول

«خودآگاه» برای هر انسانی طراحی شده که در پی فهم ریشه‌ای الگوهای تکراری زندگی، آشتی با بخش‌های سرکوب‌شده (سایه)، شناخت نقاب‌ها (پرسونا)، کشف کهن‌الگوهای روان، شفاف‌سازی ارزش‌های اصیل و تدوین نقشه‌ای عملی برای آینده است.

- **هویت بصری:** الهام‌گرفته از لوگوی رسمی و ترکیب دو نیم‌کره مغز (سمت راست: بنفش یاسی عاطفی، قلبی و معناگرا؛ سمت چپ: سبز-تیل ارگانیک، عقلانی و سرزنده) و نقطه یگانگی در مرکز (Self).
- **سبک طراحی رابط کاربری:** نئومورفیسم لطیف، گلس‌مورفیسم مینیمال، گرادیان‌های آسمانی و مرواریدی، راست‌چین کامل (RTL)، تایپوگرافی فارسی هماهنگ و واکنش‌گرا (موبایل و دسکتاپ).

---

## ۲. ساختار و امکانات پیاده‌سازی‌شده

### ۲.۱. سِیر آموزشی در ۴ مرحله جامع (Four Stages of Individuation)
1. **مرحله اول: کشف و شناخت خود:** مبانی خودشناسی، تمایز خودآگاه و ناخودآگاه، نقاب‌ها (پرسونا)، سایه، نیازهای زیربنایی و مقدمه کهن‌الگوها.
2. **مرحله دوم: بازسازی درونی:** تعارض‌های درونی، رهایی از اضطراب قضاوت، خودشفقتی و عزت‌نفس، تنظیم هیجان و هنر حیاتی مرزبندی و «نه گفتن».
3. **مرحله سوم: کشف معنا و طراحی زندگی:** ارزش‌های اصیل در برابر امیال تقلیدی جامعه، فردیت‌یابی، قطب‌نمای انتخاب‌های دشوار و چشم‌انداز آینده.
4. **مرحله چهارم: تغییر و ساخت زندگی جدید:** معماری خرده‌عادت‌ها (Tiny Habits)، شکستن اهمال‌کاری کمال‌گرایانه، مدیریت انرژی و تدوین نقشه اقدام.

### ۲.۲. ساختار استاندارد هر درس
- هدف یادگیری و اتصال به واقعیت
- آموزش مفهومی عمیق با زبان ساده
- نظریه روان‌شناختی (یونگ، شناختی، اکت)
- مثال‌های ملموس از زندگی روزمره
- دیاگرام‌های جریان آگاهی
- پرسش‌های تأملی برای خودکاوی
- یادداشت‌برداری خصوصی درون درس با ذخیره در دیتابیس
- تمرین عملی متصل
- نکات کلیدی و فهرست مراجع و کتاب‌های معتبر علمی

### ۲.۳. سیستم ارزیابی چندبعدی و ۱۲ کهن‌الگو
- **آزمون ۱۲ کهن‌الگو (کارول پیرسون - یونگ):** معصوم، یتیم، جنگجو، حامی، جستجوگر، نابودگر، عاشق، آفرینشگر، حاکم، جادوگر، فرزانه، دلقک. محاسبه طیف کامل، شناسایی کهن‌الگوهای غالب و کهن‌الگوی سایه، تحلیل نیروهای سازنده و چالش‌های ناخودآگاه.
- **ارزیابی ۶ بعد تعادل روان:** تنظیم هیجان، مهارت مرزبندی، استقلال فکری، خودشفقتی، شفافیت ارزش‌ها و استمرار در عمل.
- **شفافیت علمی:** تفکیک ارزیابی خودشناسی از آزمون‌های بالینی و عدم برچسب‌زنی.

### ۲.۴. موتور شخصی‌سازی مسیر آموزشی (Rule-Based Engine)
- تحلیل پاسخ‌ها و نمرات آزمون‌ها بدون وابستگی به هوش مصنوعی آنلاین.
- اولویت‌بندی هوشمند دروس و تمرین‌ها بر اساس نیازهای روانی کاربر (مثلاً در صورت چالش در مرزبندی یا استقلال فکری).

### ۲.۵. مربی تعاملی داخلی (Adaptive In-App Coach)
- کاملاً آفلاین و مبتنی بر سناریوهای چندشاخه.
- سه نقش: معلم، راهنما، همراه رشد.
- ارجاع هوشمند به یادداشت‌ها، حالات روحی و ترس‌های گذشته با رعایت احترام کامل.

### ۲.۶. کارگاه تمرین‌های عملی و کارنامه رشد
- تمرین‌های خلبان خودکار، نقشه پرسونا، ردیابی سایه، آزمایش شجاعت نامحبوب بودن، منشور مرزها، قطب‌نمای ارزش‌ها و کارت خرده‌عادت.
- سیستم امتیازدهی بینش (XP) و نشانگر مداومت روزانه (Streak).

### ۲.۷. نقشه زندگی من (Life Map)
- سند رسمی و یکپارچه فردیت‌یابی شامل: بیانیه هویت، ارزش‌های محوری، نقاط قوت، سایه‌ها و ترس‌ها، منشور مرزها، اهداف کوتاه‌مدت با چک‌باکس تعاملی و چشم‌انداز بلندمدت.
- آماده برای پرینت و خروجی PDF تمیز.

### ۲.۸. دفترچه شخصی (Personal Journal)
- ثبت تجارب و تأملات روزانه با تاریخ شمسی، برچسب‌گذاری، فیلتر و جستجو.

### ۲.۹. سنجش پیشرفت واقعی در ۳ ساحت
- تفکیک پیشرفت آموزشی، پیشرفت تمرینی و پیشرفت عینی در زندگی (ثبت شواهد رفتاری توسط کاربر).

### ۲.۱۰. پایگاه داده Local-First و PWA
- پایگاه داده IndexedDB مرورگر با نسخه‌بندی پایدار.
- قابلیت پشتیبان‌گیری کامل (Export به فایل JSON) و بازیابی (Import).
- کش کردن فایل‌ها و کارکرد کامل بدون اینترنت با Service Worker و Web App Manifest.

## ۳. نحوه راه‌اندازی و اجرا

### اجرای نسخه توسعه:
```bash
cd khodagah
npm run dev
```

### ساخت نسخه نهایی و بیلد تولید:
```bash
cd khodagah
npm run build
```

### پیش‌نمایش نسخه نهایی:
```bash
npm run preview
```
سپس مرورگر خود را باز کرده و به آدرس نمایش داده شده (مثلاً `http://localhost:3000` یا `http://localhost:4173`) مراجعه کنید.
